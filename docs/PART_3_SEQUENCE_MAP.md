# Movie0001 — Part III Sequence Map
# THE TRUTH

01 — THE CORE: Elias experiences the Vein's planetary-scale network.

02 — MEMORY: The Vein reveals fragments of previous contact, including evidence that it has learned from intelligent life.

03 — THE ORIGINAL PURPOSE: Elias learns the Vein was originally constructed or shaped by an ancient intelligence.

04 — THE ORISON WAR: ORISON leadership refuses to abandon the mission and attempts a final extraction.

05 — TWO SYSTEMS: Human technology and the Vein interact at planetary scale.

06 — MARA'S LAST CHOICE: Mara turns against ORISON's containment plan.

07 — THE COLLAPSE: The extraction attempt destabilizes the Core Network.

08 — ELIAS'S CHOICE: Elias can escape, but doing so leaves the Vein damaged and Nera vulnerable.

09 — THE TRANSFORMATION: Elias accepts a deeper interface to stabilise the network.

10 — THE COST: The interface permanently changes how Elias experiences memory and communication.

11 — THE ESCAPE: A surviving human team leaves Nera. Elias does not.

12 — EPILOGUE: Months later an ORISON receiver detects a signal from Nera containing a pattern no human system transmitted.
