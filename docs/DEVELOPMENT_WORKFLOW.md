# Development Workflow

## Canonical source
GitHub is the canonical versioned source for the movie project.

## Milestones
Each milestone should produce:
- Updated project files
- A clear commit message
- Updated project status
- Updated decision records when a major creative choice is made

## Quality control
Before committing:
- Check continuity against the story bible.
- Check character names and relationships.
- Check sequence numbering.
- Check that approved material is not accidentally overwritten.
- Keep secrets out of the repository.

## Principle
Build the project in the repository, not only in chat. Chat is used for collaboration; GitHub is used for the durable project record.
