# Movie0001 — Shot Specification Schema

Every production shot must record:

ID
Sequence
Scene
Part
Duration target
Shot class
Characters
Environment
Props
Camera position
Lens intent
Camera movement
Blocking
Dialogue
Action
Lighting
VFX
SFX
Music
Continuity dependencies
Asset IDs
Reference IDs
Generation/render instructions
Review status
Revision number

## Status values
DRAFT → PREVIS → LOOK-APPROVED → READY → GENERATED → REVIEW → APPROVED / REJECTED

## Rule
A shot cannot enter READY until its required assets and dependencies are identified.
