# Movie0001 — Screenplay Timing Framework

## Target
Each feature is treated as approximately 100–120 minutes until a later editorial decision changes the target.

## Part I pacing target
- Opening / Drop: 8–12 min
- Shelter / survival: 12–15 min
- First anomaly: 8–10 min
- Adaptation: 10–12 min
- Deep discovery: 12–15 min
- Cost / threat: 8–10 min
- Discovery / choice: 10–12 min
- Ending reveal: 5–8 min

## Part II pacing target
- Threshold / mystery expansion: 15 min
- ORISON return: 15 min
- Contact / conflict: 20 min
- Old expedition / confession: 15 min
- Breach / planetary response: 20 min
- Choice / revelation / ending: 15 min

## Part III pacing target
- Core / memory: 20 min
- Ancient history: 15 min
- ORISON conflict: 20 min
- Collapse / choice: 20 min
- Transformation / cost: 15 min
- Escape / epilogue: 10 min

These are planning ranges, not locked runtime.
