# Final Pipeline Gate

## Gate 1 → Gate 2
Design packages, look-dev matrix, reference management, screenplay-lock protocol and continuity/foreshadowing ledgers active.

## Gate 2 → Gate 3
Principal visual designs approved, look-dev tests approved and controlled references versioned.

## Gate 3 → Gate 4
Priority previs approved; camera, blocking and timing validated; dependencies complete.

## Gate 4 → Gate 5
Reusable assets built; shot specifications complete; QA active.

## Gate 5 → Gate 6
Shots generated/reviewed; rejected work resolved; continuity passed.

## Gate 6 → Gate 7
Editorial assembly complete; VFX/sound dependencies resolved; final continuity pass complete.

## Final
Master only after story, visual, technical and audio approval.
