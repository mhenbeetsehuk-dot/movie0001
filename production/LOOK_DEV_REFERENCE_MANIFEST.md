## Required metadata
Every reference records:
- Ref ID
- Asset ID
- Version
- Prompt/specification
- Source
- Date
- Intended use
- Lighting
- Camera/view
- Canon constraints
- Continuity implications
- Approval state
- Reviewer
- Rejection reason when applicable

## Consistency test
A reference passes only if the same asset remains identifiable across scale, lighting, camera angle and environmental context.

## Generation discipline
Generate controlled identity tests before cinematic hero images. Identity is more important than spectacle.

## Rejection categories
STORY / CHARACTER / ENVIRONMENT / MATERIAL / LIGHTING / SCALE / CONTINUITY / TECHNICAL / VFX / GENERICITY

## Versioning
Use the form REF-ID-v001. Approved changes increment the version; never silently replace an approved concept.
