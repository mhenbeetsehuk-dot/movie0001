# Technical Delivery Specification

Final technical values are selected after the production/rendering stack is locked. Until then, use project-standard placeholders rather than inventing incompatible settings.

Every asset and shot records frame dimensions, frame rate, aspect ratio, colour-management state, audio format, render version and source references.

Naming:
- Shots: P1-S01-SC01-SH001-v001
- Characters: CH-001-Elias-Venn-v001
- Environments: ENV-003-Shelter-Zone-v001
- Props: PROP-006-ORISON-Extraction-v001
- VFX: VFX-001-Elias-Adaptation-v001
- Audio: AUD-P1-S01-SC01-v001

No master output is accepted without a reproducible source chain.
