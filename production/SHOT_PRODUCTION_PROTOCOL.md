# Shot Production Protocol

## Before generation
Confirm shot ID, screenplay beat, character states, environment, props, approved references, camera and VFX/SFX requirements.

## Generate
Create the lowest-cost valid test first. Do not spend final-render effort on an unvalidated composition.

## Review
Story → performance → continuity → image → VFX → technical.

## Versioning
P1-S01-SC01-SH001-v001, then v002, v003 etc.

Only REVIEW → APPROVED shots enter editorial. Rejected versions remain traceable.
