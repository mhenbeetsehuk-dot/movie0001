# Repository Control

## Canon hierarchy
1. Core canon
2. Trilogy lock
3. Story/world/character bibles
4. Screenplay
5. Shot framework
6. Design packages
7. Approved references/assets
8. Renders
9. Editorial outputs

Higher-level canon wins conflicts.

## Change control
Every canon change records reason, affected files, impact, new decision and version increment.

No silent changes. Do not rewrite story logic merely to make a generated image easier.

Rejected renders and superseded versions remain traceable through version IDs.
