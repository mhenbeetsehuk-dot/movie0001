# Production Schedule

Dependency plan, not a calendar promise.

## Phase A — Story and Design
Canon audit; screenplay lock support; character/environment/prop/creature/VFX packages; Gate 1 review.

## Phase B — Look Development
LD-01 through LD-08; controlled references; approval/revision loop.

## Phase C — Previs
Part I priority sequences, then Part II, then Part III; geography and timing audit.

## Phase D — Asset Build
Build only approved reusable assets.

## Phase E — Shot Production
Produce by sequence, not random visual opportunity.

## Phase F — Editorial/VFX/Sound
Assemble approved material, lock dependencies, complete finishing.

## Milestones
M1 Gate 1 passed.
M2 Look development approved.
M3 Previs approved.
M4 Asset library ready.
M5 Part I shot production complete.
M6 Part I editorial assembly.
M7 Part II/III production complete.
M8 final finishing/master.

A milestone requires defined acceptance evidence, not merely effort.
