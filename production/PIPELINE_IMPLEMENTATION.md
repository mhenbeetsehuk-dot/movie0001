# Production Pipeline Implementation

01 Story Lock → approved scene/sequence IDs.
02 Design Lock → stable asset IDs and design references.
03 Look Development → approved visual references.
04 Previs → camera/blocking/timing package.
05 Asset Build → reusable production assets.
06 Shot Generation → rendered shot versions.
07 Editorial → sequence/feature assemblies.
08 VFX/Compositing → integrated final shots.
09 Sound → dialogue, ambience, Foley, effects and score.
10 Review → story, continuity, performance, image, VFX and audio QA.
11 Revision → return rejected work to the correct stage.
12 Master → only approved sequences enter final assembly.

A later stage cannot override a locked earlier decision without a documented revision.
