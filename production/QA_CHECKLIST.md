# Movie0001 — Production QA Checklist

## Story QA
- Does the shot advance or support the story?
- Does character behaviour match the screenplay?
- Is information revealed at the intended point?

## Character QA
- Correct identity
- Correct costume state
- Correct physical condition
- Correct emotional state
- Correct adaptation stage

## Environment QA
- Correct location
- Correct geography
- Correct lighting logic
- Correct scale
- Correct environmental state

## Camera QA
- Correct framing
- Correct movement
- Correct screen direction
- Correct continuity

## Technical QA
- Asset versions correct
- Resolution correct
- Frame rate correct
- Naming correct
- Audio sync correct

## VFX QA
- Effect follows established visual language
- Effect communicates story
- No unexplained visual artefacts

## Final rule
A technically impressive shot can still be rejected if it violates story or continuity.
