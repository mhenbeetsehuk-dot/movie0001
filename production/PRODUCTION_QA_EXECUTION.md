# Movie0001 — Production QA Execution 1.0

## Required checks
### Identity
Face, body, costume, injuries and adaptation state match approved reference.

### Geography
Character position, route, shelter, Vein structures and scale match established spatial logic.

### Props
Equipment possession and condition match continuity.

### Visual language
Lighting, materials, bioluminescence and human technology obey the design system.

### Story
Shot communicates the intended beat and does not reveal information prematurely.

### Motion
Physics, contact, weight, environmental interaction and camera movement remain credible.

## Disposition
PASS / PASS WITH NOTE / REWORK / REJECT.

No shot reaches editorial as PASS WITH NOTE unless the note is explicitly non-blocking and logged.
