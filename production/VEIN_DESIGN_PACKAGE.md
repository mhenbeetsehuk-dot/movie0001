# The Vein — Design Package

## Function
Planetary-scale information, energy and biological network.

## Form language
Branching biological structures combined with mineral growth. Internal illumination indicates activity and information movement.

## Forbidden visual shortcuts
- generic computer circuits
- arbitrary neon tubes
- decorative glowing roots
- unexplained floating symbols

## States
V01 — dormant trace.
V02 — local response.
V03 — active network.
V04 — defensive response.
V05 — Core Network.
V06 — planetary signal.

## Behaviour
The Vein reacts to disturbance, transmits patterns and can establish interfaces with compatible biological systems.

## Scale
Local structures should always imply connection to a much larger system.
