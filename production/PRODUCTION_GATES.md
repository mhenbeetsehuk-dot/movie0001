# Movie0001 — Production Gates

## Gate 0 — Story
Canon + screenplay + continuity.

## Gate 1 — Design
Characters + environments + props + creatures + VFX.

## Gate 2 — Look Development
Approved visual tests.

## Gate 3 — Previs
Camera + blocking + timing.

## Gate 4 — Asset Build
Reusable production assets.

## Gate 5 — Shot Production
Generate/render shots.

## Gate 6 — Editorial
Assemble and evaluate sequences.

## Gate 7 — Final
VFX + sound + colour + master.
