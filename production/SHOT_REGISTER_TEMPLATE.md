# Shot Register Template

| Field | Requirement |
|---|---|
| ID | Stable production ID |
| Part/Sequence/Scene/Shot | P/S/SC/SH identifiers |
| Class | A–F |
| Duration | Editorial estimate |
| Characters | CH IDs |
| Environment | ENV ID |
| Props | PROP IDs |
| Camera | position/lens/movement |
| Blocking | movement |
| Action | visible story action |
| Dialogue | approved line or NONE |
| Lighting | motivated source |
| VFX/SFX/Music | required elements |
| Continuity | state dependencies |
| References | REF IDs |
| Assets | asset IDs |
| Generation | tool-agnostic instructions |
| Review | DRAFT/PREVIS/LOOK-APPROVED/READY/GENERATED/REVIEW |
| Result | APPROVED/REJECTED |
| Revision | v001 etc. |

A shot cannot become READY until dependencies are identified.
