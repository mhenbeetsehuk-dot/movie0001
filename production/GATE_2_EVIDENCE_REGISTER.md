## Acceptance rule

A generated board is not automatically canon. Each controlled reference must have:
1. reference ID;
2. source render identifier;
3. approved view(s);
4. comparison against the design system;
5. continuity result;
6. explicit PASS / REWORK / REJECT;
7. reviewer/date;
8. locked asset version.

## Automatic rejection conditions

- identity drift;
- suit/gear continuity drift;
- Vein rendered as generic neon tubing;
- unexplained holographic technology;
- Core rendered as a magical/fantasy chamber;
- Nera rendered as generic Earth without controlled planetary identity;
- adaptation becomes supernatural or instantaneous;
- Vein response implies conventional speech;
- scale/geography contradicts the production bible.
