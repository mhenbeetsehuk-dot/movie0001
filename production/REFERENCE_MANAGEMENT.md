# Movie0001 — Reference Management

## Reference classes
REF-C — character
REF-E — environment
REF-P — prop
REF-V — VFX
REF-A — audio
REF-CAM — cinematography

## Reference record
Each reference must identify:
- ID
- Subject
- Source
- Purpose
- Date
- Version
- Approval status

## Canon rule
A reference may inspire a design without becoming canon. Canon requires explicit approval and repository documentation.
