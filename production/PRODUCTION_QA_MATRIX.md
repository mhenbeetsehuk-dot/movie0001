# Production QA Matrix

| Domain | Pass condition |
|---|---|
| Story | Shot communicates intended story beat |
| Character | Identity, performance and state are continuous |
| Environment | Geography and physical logic remain coherent |
| Prop | Correct asset version and damage state |
| Camera | Framing and movement support scene |
| Lighting | Motivated and consistent |
| VFX | Functional, restrained and integrated |
| Audio | Supports spatial/emotional continuity |
| Technical | Correct resolution, frame rate, naming and version |
| Canon | No unauthorised story change |

Any failed critical continuity or canon check is a REJECT regardless of visual quality.
